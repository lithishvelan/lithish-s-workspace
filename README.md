# Human Stability Test 🧪

A small interactive HTML/CSS/JavaScript project for a WebDev club task.

## Features

- 5-stage patience test
- Random messages and random events
- Score/stability system
- Timer
- Click tracking
- Wrong-move tracking
- Moving button stage
- Dark/light mode
- LocalStorage best score
- Copy-result button
- Responsive mobile design
- CSS animations
- No external libraries or assets required

## Run

Open `index.html` in a browser.

## Files

- `index.html` — page structure
- `style.css` — design, responsive layout, animations
- `script.js` — game logic and interactions
